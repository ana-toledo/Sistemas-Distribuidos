Implementação de cenários *Single-threaded* e *Multithreaded*, e geração automática de requisições.

- Pasta **client-server**: códigos de cliente e servidor multithreaded. 
- Pasta **server-multi**: códigos de servidor multithreaded, cliente single-thread.
